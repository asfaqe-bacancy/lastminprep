# PrepSprint Design System

## Design Direction

PrepSprint should not look like a typical AI product. It should feel like a premium consumer application: liquid, tactile, calm, modern, focused and polished.

Think iPhone/iOS-quality interaction, Apple-like restraint, premium productivity and editorial apps.

Avoid:
- Purple/blue AI gradients everywhere
- Robot/sparkle icons
- Neon effects
- ChatGPT-style layouts
- Excessive glassmorphism
- Generic SaaS dashboards
- Excessive AI terminology

## Core Principles

- Product first, AI second
- Large typography
- Generous whitespace
- Rounded but restrained surfaces
- Subtle borders and shadows
- Smooth transitions
- Clear hierarchy
- Mobile-first responsive design
- Light and dark mode

## Visual Language

Use neutral backgrounds and surfaces with one restrained accent color. Avoid making the whole interface colorful.

Recommended radius:
- Small: 10px
- Medium: 16px
- Large: 22px
- Feature cards: 28px
- Hero surfaces: 32px

Use pills only for status, filters, tags and compact metadata.

## Typography

Prefer:
- Inter
- SF Pro when available
- system-ui

Use strong hierarchy and sentence case. Avoid excessive uppercase labels.

## Liquid UI

Use subtle translucency and blur only where useful:
- Navigation
- Floating surfaces
- Small overlays
- Selected controls

Do not make every card glass. The interface must remain premium without blur.

## Navigation

Desktop:
- Home
- Preparations
- Documents
- Progress
- Settings

Mobile:
- Home
- Prep
- Add
- Progress
- More

## Dashboard

Focus on the next action.

Example:
"Your interview starts in 45 min"

Show:
- Active preparation
- Progress
- Recent preparations
- Study time
- Weak topics

## Preparation Setup

Use a guided flow instead of a long form:

1. Exam or Interview
2. Available time
3. Goal
4. Upload material

Use large selectable cards and clear primary actions.

## Learn Mode

Do not use chatbot bubbles. Make it feel like reading a premium article.

Show:
- Topic
- Explanation
- Key idea
- Remember
- Source

## Quiz

Use a focused question interface with a large answer area and minimal distractions.

## Interview

Use an immersive, focused screen. The user should be the visual focus, not the AI.

## Progress

Use:
- Circular progress
- Thin progress bars
- Simple charts
- Topic completion
- Time remaining

Avoid excessive analytics or gaming-style XP.

## Final Revision

Make this highly screenshot-friendly. Present a concise list of the most important concepts and weak areas.

## Motion

Use subtle iOS-like motion:
- 150-300ms transitions
- Ease-out
- Small scale changes
- Opacity transitions

Do not animate everything.

## Icons

Use Lucide icons. Avoid robot, brain, sparkle and decorative AI icons.

## Accessibility

Support:
- WCAG-friendly contrast
- Keyboard navigation
- Focus states
- Semantic HTML
- Screen-reader labels
- Comfortable touch targets

## Final Rule

Every screen should feel like a premium preparation product, not an AI demo.
